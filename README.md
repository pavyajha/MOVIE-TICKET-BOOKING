# Movie Ticket Booking System

## Project Description
This is a simple command-line Movie Ticket Booking System developed using Python. It allows the user to select a movie, choose a show timing, enter the number of tickets, and view the total booking amount.

## Features
- Displays available movies
- Allows the user to select a movie
- Provides different show timings
- Accepts the number of tickets
- Calculates the total ticket amount
- Displays a booking summary
- Shows booking confirmation

## Requirements
- Python 3.x
- No external Python libraries are required

## How to Run

### 1. Download or clone this repository
Download the project files from this GitHub repository.

### 2. Open the project folder
Make sure that `main.py` is present in the project folder.

### 3. Run the program
Open a terminal in the project folder and run:

```bash
python3 main.py
